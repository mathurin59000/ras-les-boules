Fonctionnalités

Tout ce qu'il faut pour une soirée parfaite.

Pensée par des joueurs, pour ceux qui organisent. Rien de superflu, tout ce qui compte.

🏆

Création express

Un assistant en quelques clics : nom, mode de jeu, nombre de tours. Votre tournoi est prêt avant le premier échange.

🎯

Appariements auto

Chaque tour est généré à partir du classement, sans doublons de rencontres, avec gestion des exemptions.

⚡

Scores en direct

Lancez un match, saisissez les sets, validez. Le tableau se met à jour instantanément.

⚖️

Handicap intégré

Équilibrez les niveaux : points d'avance calculés selon l'écart de classement, avec plafond réglable.

📜

Historique complet

Retrouvez chaque match, filtrez par joueur, tour ou statut, du plus récent au plus ancien.

💾

Local et rapide

Vos données restent sur votre machine, dans une base SQLite. Pas de compte, pas de connexion requise.

Comment ça marche

Trois étapes. C'est tout.

Créez

Nommez votre tournoi, choisissez le format et inscrivez vos joueurs.

Jouez

Lancez les matchs, saisissez les scores, enchaînez les tours automatiquement.

Célébrez

Clôturez, exportez le classement final et remettez les médailles.

Prêt pour le premier service ?

Téléchargez la dernière version. L'appli se met à jour toute seule dès qu'une nouvelle release sort.
